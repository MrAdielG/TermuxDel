# TermuxDel
A simple bash script that creates a del cmd that moves files to trash instead of deleting it

## Installation
```bash
git clone https://github.com/MrAdielG/TermuxDel.git && cd TermuxDel && chmod +x termux_del.sh && ./termux_del.sh
```

## Usage 
del file1.txt
del file1.txt file2.txt
del folder
